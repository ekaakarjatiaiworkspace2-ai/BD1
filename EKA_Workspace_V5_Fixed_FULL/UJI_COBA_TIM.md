# Uji Terima Pengguna (UAT) — EKA Workspace V5

Tandai checklist setelah mencoba pada komputer Anda; screenshot mockup/tes browser bukan bukti UAT produksi.

## Ahmad / BD-R&D
- [ ] Login Ahmad, ganti kata sandi.
- [ ] Beranda, Tugas Saya (4 macro), Kelola Tim, Data, Tools, Chat, Meeting, Timeline dapat dibuka.
- [ ] Klik satu macro, buka subtask, lihat tujuan, checklist, hasil, dan bukti.
- [ ] Atur jadwal tugas, sertakan alasan; target awal tetap tercatat.
- [ ] Terima hasil Donny/Angga yang telah dikirim untuk diperiksa.
- [ ] Tolak data yang belum lengkap atau belum punya sumber; tandai Siap hanya setelah validasi.
- [ ] Buat meeting, bagikan ringkasan dan periksa siapa yang telah membaca.

## Donny / Data Science
- [ ] Melihat 4 tugas besar DS saja, bukan Finance/BD.
- [ ] Mengisi checklist dan hasil, lalu kirim untuk diperiksa Ahmad.
- [ ] Mencoba menandai sendiri Selesai → harus ditolak.
- [ ] Melihat data terkait tetapi tidak memperoleh dokumen mentah yang belum disetujui.
- [ ] Mengubah status dan catatan hasil pengujian tools, tanpa bisa menyetujui tools sendiri.

## Angga / Finance
- [ ] Melihat 3 tugas besar Finance dan 120 permintaan data.
- [ ] Mengunggah dokumen uji (jangan data pribadi/rahasia dulu), ubah status menjadi Diterima.
- [ ] Coba langsung menandai Siap Dipakai → harus ditolak.
- [ ] Menyimpan kendala dan menyiapkan dokumen untuk klarifikasi.

## Management
- [ ] Login management; hanya ringkasan, 2 tugas review, Timeline agregat, meeting yang dibagikan, keputusan.
- [ ] Tidak dapat melihat data keuangan atau berkas mentah melalui API.
- [ ] Menyelesaikan subtask review setelah menyerahkan alasan dan checklist.
- [ ] Tidak dapat menyetujui tugas Donny atau mengubah data Finance.

## Tampilan mobile
- [ ] HP 320–430px: navigasi bawah dan tombol menu berfungsi.
- [ ] Menu geser dapat ditutup melalui tombol X, overlay, ESC pada keyboard, dan memilih halaman.
- [ ] Dashboard, tugas dan chat tidak memaksa scroll horizontal. Timeline boleh digeser horizontal secara internal.
- [ ] Uji tampilan 768px (tablet) dan desktop besar.
- [ ] PWA Add to Home Screen hanya diuji pada alamat HTTPS; pastikan sertifikat valid pada HP.

## Sebelum digunakan sehari-hari
- [ ] Verifikasi akses jaringan sesuai kebijakan IT.
- [ ] Backup dan pemulihan database serta dokumen diuji.
- [ ] Penanggung jawab sumber legal, teknis konstruksi, dan pajak ditetapkan.
- [ ] Jangan menggunakan model keuangan dummy sebagai keputusan kredit.
